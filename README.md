# COVID-19 Web Scraping

A mini Python project that extracts COVID-19 data from Worldometers, cleans the data, and exports it to a CSV file.

## Tools Used

* Python
* Pandas
* Requests
* BeautifulSoup

## Project Steps

1. Extract data from the Worldometers website.
2. Parse the HTML table using BeautifulSoup.
3. Clean and transform the data using Pandas.
4. Convert numerical columns to the correct data type.
5. Export the cleaned dataset to `Data.csv`.

## Files

- `covid_19_web_scraping.py` — Python script for web scraping and data cleaning.* `Data.csv` — Cleaned dataset.
